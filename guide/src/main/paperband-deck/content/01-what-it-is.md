- One markdown source → a printable PDF **and** a browsable static site
- A **card** is a page, a nav entry, and a PDF destination
- Runs as a Maven plugin, so books build in CI like any other artifact

## Aside

Guides, runbooks, migration playbooks — structured content that has to stay
correct and ship repeatedly.

## Notes

Thirty seconds. The pitch is "structured content, built like code" — the card
is the unit that makes that work, because it's addressable in all three
outputs at once.
