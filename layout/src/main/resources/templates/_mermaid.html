{# Mermaid diagrams — ```mermaid fences render through the bundled blocks/mermaid.html into 
 holding the diagram source;
   this loader turns each into inline SVG in the browser. Unlike Prism, the
   library is fetched only when the page actually contains a diagram (it's
   ~2.5MB) — and rendering is CPU work AFTER the network goes quiet, so the
   renderer's network-idle wait can't guarantee the PDF snapshots finished
   diagrams. The contract that does: a page script with post-load layout work
   pushes a promise into window.paperbandPending, and the Playwright renderer
   and measurer await Promise.all(window.paperbandPending) before
   snapshotting/measuring. A failed load or a diagram that doesn't parse
   rejects the promise, failing the PDF build loudly rather than shipping a
   half-rendered page; in a live browser the same error lands on the console
   and mermaid shows its own error box in place.

   vars.mermaidTheme picks mermaid's colour theme (default | dark | forest |
   neutral | base) — set it in the book's vars to match a dark page theme. #}
