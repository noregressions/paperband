Cards belong to their section whether or not they also carry axis values; only when an axis divider fires on the same card does it take the section divider's place. Mirrors _tier-divider-base.html's shape, but sections have no colour concept, so there's no inline background and no axis badge line — just the title, and (unless the section resolved to the "minimal" named preset -- see NamedTemplates -- via its own folder paperband.yaml or the book-wide sections.landing.template default) a card count and table of contents, matching whatever the section's site landing page shows. Expects: section {id, label, count, minimal, body, bodyCards, cards: [{id, title, oneliner, effort}]}. A divider whose section wrote a body also carries `has-body`: an empty divider is a title centred on a sheet, but a body is prose, and prose set centred at a title's measure is unreadable — see book.html, which turns the centring off for that case and hands the body the card measure instead. Anchor id is "section-divider-{sectionId}" — deliberately a different prefix from "axis-divider-{axisName}-{valueId}" so PagesReport can tell the two apart generically, without needing to know which axis names or section ids a given book uses.
