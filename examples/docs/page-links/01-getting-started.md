# Getting started

A page with an `id` in its front matter can be linked from any other page by that id, wherever
its file is and whatever it's called. These three pages link to each other this way.

- With text of its own: [how to install it](#install).
- With no text, the link shows the page's title: [](#install).
- With `#` as the text, it shows the page's number: see Chapter [#](#install) and
  Appendix [#](#keys).

The number is the target's `chapter` (or `appendix`) front matter. In a web site each link goes
to the page's own file; on one page, or in a PDF, it goes to where that page starts.
