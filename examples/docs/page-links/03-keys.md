# Front matter keys

| Key        | What a link uses it for                              |
|------------|------------------------------------------------------|
| `id`       | The name other pages link to: `[text](#id)`          |
| `title`    | The text of a link written with none: `[](#id)`      |
| `chapter`  | The text of a link written as `[#](#id)`             |
| `appendix` | The same, for a page that has no `chapter`           |

Chapter [#](#start) shows each kind of link.
