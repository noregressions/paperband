paperband

Held together by paperband.

A fast, Java-powered engine to convert your Markdown into beautiful PDFs and static websites.

View on GitHub Quick Start

Why Paperband?

Write Once

Focus on your content using standard Markdown. Let the engine handle the complex layout and typesetting rules.

Export Anywhere

Generate print-ready PDFs and responsive HTML websites from the exact same source files in one build.

Java Native

Built for the JVM. A Maven plugin, so a book builds the way the rest of your project does — same reactor, same phases, same CI.

Quick Start

Add the plugin to the project that holds your book:

<plugin>
    <groupId>dev.noregressions.paperband</groupId>
    <artifactId>paperband-maven-plugin</artifactId>
    <version>0.1.1</version>
    <executions>
        <execution>
            <goals><goal>build</goal></goals>
            <configuration>
                <input>${project.basedir}/docs</input>
                <output>${project.build.directory}/book.pdf</output>
            </configuration>
        </execution>
    </executions>
</plugin>

mvn package now builds the book. Every goal also runs on its own, no execution needed:

# Generate a PDF
mvn paperband:build -Dpaperband.input=docs/ -Dpaperband.output=build/book.pdf

# Generate a website
mvn paperband:site -Dpaperband.input=docs/ -Dpaperband.outputDirectory=build/html

# Check what a book contains, without rendering it
mvn paperband:structure -Dpaperband.input=docs/
